## 配置手順

1. `index.html` をGitHub Pages等のHTTPSホスティングへ配置する
2. LINE DevelopersのLIFF設定で、エンドポイントURLを配置先URLへ変更する
3. リッチメニューのURLはLIFF URL（`https://liff.line.me/2011372741-pVTKApdl`）のままにする
4. `index.html` の `API_URL` は現在のGAS URLのままにする
5. LIFF URLから再テストする
